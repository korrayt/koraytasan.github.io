# BİR DOST — Marka Kimliği (Konsept v1)

## Kimlik
- Ad: **BİR DOST** (kurumsal yazımda büyük harf, ürün konuşmasında “Bir Dost”).
- Ana mesaj: **İyilik sipariş et. Ulaştığını gör.**
- Yan mesaj: **Dostlara, dostlardan.**
- Mama paketleri üzerinde: **bir dost** / altında **dostlara 🐾**.
- Ses: samimi, net, yargılayıcı değil, sevgi dolu, mahalle kültürüne yakın.
- Teslim videosu formülü: Mahalle + destek verenin açık rızayla belirlediği adı + mama adedi + dostlara teslimat + teşekkür.
